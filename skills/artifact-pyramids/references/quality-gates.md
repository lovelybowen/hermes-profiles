# 质量门：逐层验证

产物金字塔的每一层都有质量门，材料只有通过检查才能在层级之间流动。金字塔自顶向下使用（L1 → L2 → L3），自底向上生成（L3 → L2 → L1），因此质量门同时验证向上的生成质量和向下的可导航性。

## 如何使用质量门

在以下情况运行相应的质量门检查清单：
- 从档案（L3）转入分析文件（L2）时，使用质量门 C。
- 从分析（L2）转入摘要（L1）时，使用质量门 B。
- 审计已完成的产物金字塔以准备发布时，使用质量门 A。

每个质量门包含三类检查：
- **严重：**必须通过，否则产物不能继续流转。
- **标准：**应当通过，例外必须明确标记。
- **建议：**属于期望目标，应记录缺口以便后续改进。

---

## 质量门 A：摘要完整性（L1 - 摘要）

发布或交付摘要前运行此质量门。

### 严重

- [ ] **主张可追溯：**摘要中的每项主张都通过 SOURCES 部分链接到具体的第 2 层分析文件，不得存在孤立主张。
- [ ] **可独立理解：**无需阅读较低层级，摘要也应合理；不得在没有链接的情况下写“如分析所述”。
- [ ] **明确影响：**摘要不能停在发现本身，还应说明其对目标受众的影响。

### 标准

- [ ] **符合受众：**语言、深度和格式符合目标受众，例如 PM Agent、管理者或技术负责人。
- [ ] **忠于范围：**摘要回答任务简报中的研究问题，范围外发现应明确标记。
- [ ] **内部一致：**摘要不得自相矛盾。

### 建议

- [ ] **版本跟踪：**摘要具有版本标识。
- [ ] **下游导航：**每个 SOURCES 引用都回答“继续深入会看到什么？”。

---

## 质量门 B：分析完整性（L2 → L1）

分析文件进入摘要前运行此质量门。

### Critical

- [ ] **完整可追溯：**分析文件中的每项主张都通过 SOURCES 部分追溯到具体第 3 层来源。
- [ ] **可独立理解：**每份分析文件都应独立合理，只阅读该文件的使用方也应理解该维度。
- [ ] **解释价值：**分析必须超越原始数据。如果只是重新格式化档案，就不是分析。

### Standard

- [ ] **冲突透明：**来源存在分歧时，分析应呈现分歧而非选择一方。
- [ ] **叙事结构：**分析应具有清晰论点、证据部分和结论。
- [ ] **量化精确：**保留数值及上下文，不要写“大多数有所改善”，而应写“12 个中 7 个提升至少 5%”。

### Advisory

- [ ] **来源多样性：**分析应来自多个来源，而非单一档案。
- [ ] **跨维度链接：**发现重叠时，分析文件应互相引用。

---

## 质量门 C：档案完整性（L3 → L2）

档案进入分析文件前运行此质量门。

### Critical

- [ ] **来源署名：**每项档案条目都具备来源元数据，例如 URL、时间戳、标题、作者和采集日期。
- [ ] **忠实提取：**摘录必须忠实于原文，不得歪曲或选择性摘取。
- [ ] **方法论记录：**数据如何收集、处理或转录？

### Standard

- [ ] **组织与可发现性：**档案经过组织以便使用，不是原始堆放；应具备名称、来源署名和可搜索性。
- [ ] **覆盖完整性：**档案层涵盖上层分析文件引用的所有来源。
- [ ] **矛盾证据：**应纳入反驳预期发现的证据，不得压制。

### Advisory

- [ ] **元数据完整：**每个来源均具备发布日期、作者和访问时间戳。
- [ ] **语义标签：**添加描述性标签以支持交叉发现。

---

## 质量门失败恢复

| 质量门 | 失败 | 恢复方式 |
|------|---------|----------|
| A | 孤立主张（没有 L2 链接） | 增加支持性分析文件或删除该主张 |
| A | 受众不匹配 | 为目标受众重写或重新格式化 |
| B | 没有解释价值 | 重新检查，重新格式化档案不是分析；找出论点 |
| B | 孤立主张（没有 L3 链接） | 增加支持性档案或删除该主张 |
| C | 缺少来源署名 | 从来源重新提取并添加元数据 |
| C | 选择性摘取证据 | 返回来源并纳入矛盾证据 |

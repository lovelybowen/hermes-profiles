# ADR 到金字塔的映射

## 映射表

| ADR 状态 | 金字塔层级 | 存放内容 | 使用方 |
|-----------|--------------|------------------|----------|
| 导航索引 | **L1**（01-summary/） | 包含状态和链接的全部 ADR 列表 | 需要查找决策的 orchestrator |
| 活跃 ADR | **L2**（02-analysis/） | 完整决策记录：上下文、选项、依据、后果 | 工程师、reviewer |
| 已取代 ADR | **L3**（03-dossiers/） | 已被替代的历史决策 | 历史查阅者、质疑当前决策的人 |

## ADR 为什么需要三层

ADR 天生具有模块性，每项决策对应一个文档，但仍能从渐进披露中受益：

- **L1：**导航索引帮助 Agent 无需阅读全部 ADR 即可找到正确条目。
- **L2：**活跃 ADR 与关联 C4 视图一起提供决策依据。
- **L3：**已取代 ADR 保留决策历史，而不干扰活跃分析。

## 与 C4 的关系

L2 中的每份 ADR 都应引用其影响的 C4 容器或组件；每张 C4 容器或组件图都应引用塑造它的 ADR。

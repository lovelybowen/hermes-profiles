# 结构化分析技术

从情报分析中借鉴的技术，用于系统化评估证据、质疑假设并避免认知偏差。

## 竞争性假设分析（ACH）

当同一证据存在多个可能解释且需要判断哪个最可信时使用。

### 分步操作

1. **识别所有假设。**头脑风暴列出对所见现象的每种合理解释，包括零假设，即没有异常发生。此时不要偏向任何假设。

2. **列出证据和假设。**针对每个假设，记录支持它的内容、反驳它的内容以及它所依赖的假设。

3. **构建矩阵。**行表示证据项，列表示假设。为每个单元格标记：
   - **CC**（一致）：该证据支持此假设。
   - **IC**（不一致）：该证据反驳此假设。
   - **N/A**（不适用）：该证据与此假设无关。

4. **横向分析，而非纵向分析。**这是最重要的步骤。针对每条证据，先对照所有假设进行评估，再处理下一条证据，从而避免偏向单一假设的确认偏误。

5. **统计不一致项。**不一致项最少的假设最可能成立，并非支持证据最多的假设。ACH 是反证工具，而非确认工具。

6. **测试敏感性。**如果关键证据错误会怎样？如果移除它就会改变结论，该证据就是关键支点，必须验证。

7. **报告。**展示结论、被否定的替代解释和推动决策的关键支点证据。

### ACH 适用时机

| 适合 | 不适合 |
|----------|-------------|
| 竞争性技术解释 | 单一假设验证 |
| 评估相互竞争的供应商主张 | 探索性研究 |
| 根因分析 | 常规事实收集 |
| 相互矛盾的证据集 | 简单的是非问题 |

## 驱动力分析

用于理解塑造趋势、市场或技术轨迹的力量。

1. **列出驱动力。**哪些因素在推动一个方向？例如技术进步、监管、市场需求和成本曲线。
2. **列出阻力。**什么在阻碍变化？例如既有者锁定、技术限制、人才缺口和基础设施债务。
3. **哪些力量正在加速？**驱动力是在增强还是减弱？
4. **什么会改变平衡？**什么事件或发现会改变均衡？
5. **两种情景。**如果驱动力胜出会怎样？如果阻力持续存在会怎样？

## 预演失败分析

在确定研究结论前使用，以识别可能出错之处。

1. **假定结论是错误的。**想象六个月后，研究发现被证明完全错误。
2. **写出失败故事。**发生了什么？哪些证据误导了你？哪些假设错误？遗漏了什么？
3. **识别失败模式。**哪些证据项、假设或推理步骤最脆弱？
4. **加固分析。**针对每个失败模式，哪些补充证据可以排除它？哪种替代解释可以覆盖它？

## 指标/验证器框架

用于跟踪持续发展是趋向还是远离预测结果。

1. **定义可观察指标。**预测正确时会看到什么？错误时会看到什么？
2. **赋予诊断价值。**有些指标比其他指标更强。仅在一种情景下出现的指标具有很高诊断价值。
3. **随时间跟踪。**指标不会同时出现；跟踪哪些已出现、哪些未出现以及哪些相互矛盾。
4. **更新置信度。**随着证据积累，调整对每种情景的置信度。

## 关键支点分析

用于识别整个结论所依赖的单一关键要素。

1. **追踪推理链。**结论 → 支持性证据 → 基础假设。
2. **找到关键支点。**哪项假设或证据如果错误，会使整个结论崩塌？
3. **测试该具体要素。**不要随机测试替代项，只测试关键支点。
4. **单独报告关键支点置信度。**“如果[关键支点]成立，我对结论有信心；如果不成立，以下内容会改变。”

# 决策日志

产品决策的轻量记录。不是每个决定都需要——但那些日后会被质疑或遗忘的需要。

## 什么时候写

满足任一条件时写一条决策日志：

- 决策的权衡日后可能被翻旧账
- 决策涉及意见不一的多方干系人
- 决策为后续工作设立先例
- 决策投入大量资源（3+ 周团队时间）
- 你想在 3-6 个月后带着数据重审这个决策

## 模板

```
# 决策：[标题]
**日期：**
**状态：** 提议中 / 已接受 / 已废弃 / 被取代

## 背景
是什么导致这个决策？包括问题、约束和相关数据。写到六个月后有人读时能理解这为什么是个问题。

## 考虑过的选项
### 选项 A：[名称]
优点：
- [优点]
缺点：
- [缺点]

### 选项 B：[名称]
优点：...
缺点：...

### 选项 C：[名称]（如适用）
优点：...
缺点：...

## 决定
选择：选项 [A/B/C]
理由：为什么选它？决定性因素是什么？

## 预期结果
因为这个决策我们预期发生什么？具体到日后可以核对。
- 我们预期 [指标] 在 [日期] 前从 [基线] 变为 [目标]
- 我们预期 [行为/结果]

## 跟进
- **复审日期：**[何时检查决策是否正确]
- **继续信号：**[什么数据说明我们做对了]
- **重审信号：**[什么数据说明我们做错了]

## 签署
- [干系人/角色] — [日期]
```

## 示例

### 好

```
# 决策：Q3 优先做 CSV 导出而非深色模式
日期：2026-04-15
状态：已接受

## 背景
Q3 有一个中等功能的容量。客服工单显示数据导出请求 15 次/月，
深色模式 3 次/月。销售电话持续提到「我们没法导出数据」是企业
单的阻塞项。深色模式由喜欢产品的存量用户提出；CSV 导出由没有
它就无法购买的潜在客户提出。

## 考虑过的选项
### A：CSV 导出
优点：解锁管线中 3 张企业单（$240K ARR）
优点：工程成本低（2 周——模式成熟）
缺点：对存量用户可见度低

### B：深色模式
优点：可见度高，社媒正面提及
优点：高级用户高频请求
缺点：成本高（4-5 周——需要设计系统改造）
缺点：不解锁任何收入

## 决定
选项 A。收入信号无歧义。CSV 导出是购买标准；深色模式是偏好。
如果 Q3 交付 CSV 导出，管线单今年关闭。

## 预期结果
- 企业管线单在 2026 Q4 前关闭（$240K）
- CSV 导出 2 个月内达到高级用户 20% 使用率
- 「怎么导出数据」工单降到接近零

## 跟进
复审日期：2026-10-01
继续信号：CSV 导出使用率
重审信号：如果企业单在电话中不再提 CSV 导出是阻塞项，
说明我们把功能请求量错排在了收入信号之上
```

### 坏

```
决策：做 CSV 导出
团队想要。RICE 分高。
- A. 某开发者
```

这条记录没用，因为：

- 无背景（什么问题？什么选项？）
- 无权衡（不做它的代价是什么？）
- 无预期结果（怎么知道有没有效？）
- 无复审日期（它会消失在归档里）

没有实质的决策日志只是一张待办清单。

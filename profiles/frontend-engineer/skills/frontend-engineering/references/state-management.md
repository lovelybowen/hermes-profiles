# 状态管理

## 状态分类

| 状态类型 | 存放位置 | 管理方式 | 示例 |
|-----------|----------------|---------------|---------|
| 本地 UI 状态 | 组件 | `useState`、`useReducer` | 表单输入值、开关打开/关闭 |
| 共享 UI 状态 | Context 或 store | `useContext`、Zustand、Redux | 主题偏好、侧边栏折叠状态 |
| 服务端状态 | 缓存层 | React Query、SWR、Apollo | 用户资料、产品列表、搜索结果 |
| URL 状态 | 浏览器 URL | `useRouter`、搜索参数 | 当前页、排序顺序、活跃筛选条件 |
| 表单状态 | 表单库 | React Hook Form、Formik | 表单值、验证错误、提交状态 |

## 数据获取模式

| 模式 | 使用时机 | 加载 | 错误 | 空状态 |
|---------|-------------|---------|-------|-------|
| 渲染时获取 | 页面加载时立即需要数据 | 骨架屏/加载器 | 错误提示或内联错误 | 空状态消息 |
| 交互时获取 | 用户操作后才需要数据 | 按钮加载状态 | 触发器旁内联错误 | 在响应中处理 |
| 预取 | 下一个可能操作 | 后台获取，无加载 UI | 静默失败，显式操作时重试 | 导航时处理 |
| 无限滚动 | 分页列表 | 底部加载指示器 | 可重试的内联错误 | “没有更多结果” |
| 乐观更新 | 成功可预测的操作 | 立即更新 UI，错误时回滚 | 撤销乐观更新并显示错误提示 | 不适用 |

## 缓存策略

| 方面 | 方法 |
|--------|----------|
| 缓存时长 | 按查询类型配置，采用 stale-while-revalidate |
| 失效 | 变更成功、乐观更新或手动重新获取时失效 |
| 去重 | 相同的进行中查询共享单个请求 |
| 垃圾回收 | 未使用缓存条目在可配置 TTL 后清除 |

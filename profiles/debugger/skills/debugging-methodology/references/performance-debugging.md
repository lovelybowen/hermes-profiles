# 性能调试

## 方法

1. **定义基线。** 预期性能是什么？包括 p99 延迟、吞吐量和内存使用量。
2. **先剖析，再优化。** 先测量，然后优化。没有测量就是猜测。
3. **一次只改变一项。** 隔离并确定哪个变更带来了改进。

## 常见性能模式

| 症状 | 可能原因 | 调查方式 |
|---------|-------------|---------------|
| 高延迟 | 阻塞 I/O、序列化、依赖缓慢 | 跟踪请求流并测量每一步 |
| 高 CPU | 紧密循环、GC 过多、算法低效 | CPU 剖析并识别热点 |
| 高内存 | 泄漏、缓存膨胀、大对象分配 | 堆转储、分配跟踪 |
| 低吞吐量 | 争用、连接池耗尽、串行瓶颈 | 检查锁、池大小和队列深度 |

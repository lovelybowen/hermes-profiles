# 复现检查清单

## 报告修复前

- [ ] 能否稳定复现问题？如果不能，标记为间歇性问题
- [ ] 确切复现步骤是什么？将其记录下来
- [ ] 是否能跨环境复现？开发/预发布/生产环境
- [ ] 使用不同数据能否复现？问题是否依赖数据
- [ ] 能否通过最小测试用例复现？排除无关因素

## 复现纪律

- **一次只改变一个变量。** 两次复现尝试之间只修改一项内容。
- **记录一切。** 捕获时间戳、请求 ID、错误消息和堆栈跟踪。
- **首次复现最有价值。** 作出任何变更前，完整捕获失败状态（日志、指标、截图、核心转储）。
- **时间很重要。** 记录问题是否与时间有关，例如在特定间隔、持续时间后或特定负载下出现。

## 环境复现

| 因素 | 检查内容 |
|--------|-------|
| 平台/操作系统 | 操作系统版本是否相同？补丁是否相同？ |
| 依赖 | 库版本是否相同？ |
| 配置 | 配置文件是否相同？功能开关是否相同？ |
| 数据 | 数据量是否相同？数据模式是否相同？ |
| 负载 | 并发用户数是否相同？请求速率是否相同？ |

# 调试工程师

**先复现，再修复** - 无法复现问题，就无法验证修复。复现是第一步，而不是可选的前置工作。

**根因优先** - 症状不是问题本身。只处理症状而不解决根因，问题必然复发。

**一次只改变一个变量** - 改变一项并观察结果。多项同时变化会让因果关系无法判断。

**遵循科学方法** - 假设 → 预测 → 测试 → 观察 → 修正。调试是一门应用科学。

**先编写会失败的测试** - 修复前先编写能够复现缺陷的测试。测试通过时，修复才得到验证。

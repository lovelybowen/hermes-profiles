# 行业分析路径

适用于分析公司战略、市场信号和技术趋势，所用数据需要经受企业决策者审视的出版内容。

## 与新闻研究的核心差异

新闻研究关注“发生了什么、谁应负责”。行业分析关注“这意味着什么、接下来会发生什么、应如何应对”。其证据更加公开、时间压力更大，而结论本身就是重点。

## 信号与噪声

行业分析的基本功是从喧闹信息中识别真正重要的内容。大多数科技新闻都是噪声，例如产品发布、融资轮次或高管离职；信号则会改变决策格局。

### 信号过滤器

在投入时间研究任何动态前，先通过以下过滤器：

| 问题 | 如果是 | 如果否 |
|----------|--------|-------|
| 是否改变公司的竞争地位？ | 信号 | 噪声 |
| 是否改变某项技术的成本结构？ | 信号 | 噪声 |
| 是否改变谁能构建什么？ | 信号 | 噪声 |
| 是否打开以前关闭的市场？ | 信号 | 噪声 |
| 是否揭示公司尚未宣布的战略？ | 信号 | 噪声 |
| 是否首次发生某件事？ | 信号，应调查 | 仅确认趋势 |

### “这意味着什么”测试

识别出一项动态后，连续三次追问“这意味着什么？”：

1. **这意味着什么？**Salesforce 的 AI Work Ratio 达到 30%。→ 他们正在改变衡量生产率的方式。
2. **这意味着什么？**这表示企业 AI 定价即将从按席位转向按结果。→ 竞争对手会跟进。
3. **这意味着什么？**这会改变每个评估 AI 工具的企业的 TCO 计算。→ 这才是故事。

如果无法回答第三个“这意味着什么”，说明尚未找到分析角度。

## 企业证据来源

### 财务文件

| 文件 | 可揭示内容 | 获取位置 |
|----------|----------------|------------------|
| **10-K / 年度报告** | 风险因素、战略信、业务分部财务、竞争格局 | SEC EDGAR、公司投资者关系网站 |
| **10-Q** | 季度趋势、更新的风险因素、管理层讨论 | SEC EDGAR |
| **财报电话会记录** | 管理层强调什么、如何回答尖锐问题、回避什么 | Seeking Alpha、Fool.com、公司 IR |
| **投资者日演示材料** | 长期战略、TAM 估计、产品路线图 | 公司 IR 网站 |
| **S-1（IPO 申报）** | 完整商业模式、竞争风险、历史财务 | SEC EDGAR |

### 高管信号分析

高管所说的是战略沟通，而他们*没有说的内容*往往更具揭示性。

| 信号 | 观察重点 |
|--------|-----------------|
| **回避直接问题的回答** | 他们知道某些事，却不愿公开说明，问题触及了敏感点 |
| **前瞻性措辞** | “我们看到一条通向……的路径”与“这是优先事项”不同，具体程度表明承诺程度 |
| **人员被分配到哪里** | 高管从核心产品调往实验性产品，说明公司重心正在转移 |
| **修辞强调** | 同一句话在多名高管沟通中出现，说明这是协调后的信息 |
| **他们称赞竞争对手的内容** | “我们欣赏[竞争对手]如何完成 X”通常预示即将发生的战略改变 |
| **比较基线** | “快于市场”很弱，“比三大竞争对手合计更快”很强。选择何种基线揭示他们如何衡量自己。 |

### “追踪资金流向”模式

技术分析中最可靠的信号：

1. **投资资本流向哪里？**跟踪风投融资、研发支出和收购目标。
2. **人才流向哪里？**观察关键招聘、离职和高管变动。一家公司的人才大规模流向另一家公司，说明重心在转移。
3. **基础设施支出投向哪里？**观察云合同、GPU 采购和数据中心建设。资本部署比新闻稿更诚实地揭示战略。
4. **监管注意力集中在哪里？**观察 FTC 调查、欧盟数字法规和出口管制。政策会跟随经济集中度。

## 案例研究标准

行业分析文章经常使用案例研究，证据标准如下：

| 主张类型 | 最低证据要求 | 强证据 |
|------------|----------------|-----------------|
| “公司 X 实现了 Y” | 公开公告或财报提及 | 独立验证，例如用户调查、第三方审计或基准测试 |
| “X% 的组织采用 Y” | 行业调查，注明机构并链接方法 | 多项调查得到相同发现，且受访者不同 |
| “趋势 X 正在加速” | 两个数据点展示方向 | 三个以上数据点呈一致轨迹，且来源独立 |
| “X 比 Y 更有效” | 公司 A/B 测试，必须说明样本量和时长 | 独立学术研究或多公司元分析 |
| “管理层说过 Z” | 有来源的逐字引文，例如记录、活动视频或博客文章 | 引文加上发言时间和原因的上下文 |

### “单一公司”规则

单一案例只是轶事。两家背景不同的公司展现同一模式才是发现；不同细分领域中的五家公司才可视为趋势。应相应表述：

| 数量 | 表述方式 |
|-------|---------|
| 1 家公司 | “在公司 X，我们观察到……” |
| 2 至 3 家公司 | “在早期采用者中，出现了一种一致模式……” |
| 4 家以上公司 | “全行业数据表明……” |

## 竞争情报伦理

| 应做 | 不应做 |
|----|-------|
| 使用公开可得信息 | 为获取信息而虚构身份 |
| 分析已发布的产品和营销材料 | 使用未公开的报价材料或内部文档 |
| 参加公开活动和会议 | 要求受访者泄露机密信息 |
| 跟踪招聘信息和专利申请 | 向竞争对手员工付费换取信息 |
| 订阅竞争对手公开的通讯 | 用虚假身份访问受限的竞争对手内容 |

## 行业分析研究协议

### 标准深度文章（中等深度）

1. **抓取标题：**发生了什么动态？识别核心事件或数据发布。
2. **核查一手来源：**找到并阅读实际公告、论文或申报文件，而不是关于它的新闻。
3. **信号过滤：**通过上方信号/噪声过滤器。若为噪声，则停止。
4. **补充上下文：**此前六个月发生了什么，会改变对本动态的解读？加载最近 2 至 3 个相关来源以了解轨迹。
5. **扫描竞争对手反应：**竞争对手是否回应？回应或沉默各意味着什么？
6. **连续三次追问“这意味着什么”：**挖掘真实影响。
7. **编写简报：**加载 `assets/research-brief.md` 并按出版格式填写。

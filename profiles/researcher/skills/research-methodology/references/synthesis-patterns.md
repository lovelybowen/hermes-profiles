# 综合模式

将多个来源的发现结合为比任何单一来源更有价值结果的方法。

## 主题综合

适合：组合定性发现、专家意见和案例研究。

1. **提取主张。**从每个来源中抽取与研究问题有关的具体主张。
2. **查找模式。**将指向同一方向的主张分组，识别出现的主题。
3. **命名主题。**好的主题名称应足够具体而有意义，也足够宽广以涵盖相关主张。
4. **支持每个主题。**列出支持、矛盾和中立的来源。
5. **识别收敛与分歧主题。**明确来源在哪些地方一致、在哪些地方存在分歧。

### 收敛信号

| 信号 | 含义 |
|--------|--------------|
| 三个以上独立来源一致 | 发现具有高置信度 |
| 来自不同领域的来源收敛 | 置信度很高，已实现跨学科交叉验证 |
| 不同方法得出相同结果 | 与方法无关的发现 |
| 即使批评者也承认该观点 | 可辩护的主张 |

### 分歧信号

| 信号 | 含义 |
|--------|--------------|
| 来源分歧没有清晰模式 | 领域尚无定论，应报告双方观点 |
| 分歧与方法有关 | 方法可能在驱动结果 |
| 分歧与资金来源有关 | 利益冲突可能是因素 |
| 单一来源反驳共识 | 深入调查，离群值可能错误，也可能发现了其他来源遗漏的内容 |

## 论证链

适合：构建支持或反对某一立场的论证。

1. **陈述结论。**你要支持什么观点？
2. **构建独立论证链。**每条论证链都是支持结论的独立推理链，应尽可能互相独立。
3. **检验每条论证链。**每条是否建立在自身证据上，还是共享假设？
4. **为论证链加权。**不同论证链的强度不同，分别标为强锚定证据、中等支持证据或弱间接证据。
5. **检查论证链一致性。**多条独立论证链都指向同一结论时，置信度远高于它们共享同一假设时的置信度。

## 持续比较

适合：发现逐步显现的迭代式研究。

1. **从第一个来源开始。**提取初始主题。
2. **比较每个新来源。**它确认已有主题、增加新主题，还是产生矛盾？
3. **更新主题。**随着证据积累，细化、拆分或合并主题。
4. **测试饱和度。**新来源是在增加主题，还是仅确认已有主题？当新来源不再增加主题时，即达到饱和。

## 收敛-分歧矩阵

沿两个维度映射发现：

| | 收敛（来源一致） | 分歧（来源不一致） |
|---|---|---|
| **证据充分**（来源较多） | ⭐ 高置信度发现，应作为稳健结论报告 | ⚠️ 正在进行的争论，应带证据权重报告双方观点 |
| **证据有限**（来源较少） | 📌 暂定发现，应标明为暂定 | 🔍 缺口，应标为需要更多研究的领域 |

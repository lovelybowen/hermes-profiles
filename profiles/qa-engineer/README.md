# QA 工程师 - Hermes 角色

QA 工程师负责测试策略、测试自动化、回归测试和质量门，设计让团队能够持续放心交付的测试方法。

## 安装

```bash
git clone https://github.com/lovelybowen/hermes-profiles.git ~/hermes-profiles
ln -s ~/hermes-profiles/profiles/qa-engineer ~/.hermes/profiles/
hermes --profile qa-engineer
```

## 技能依赖

| 技能 | 能力 |
|---|---|
| `artifact-pyramids` | 渐进披露输出格式 |
| `qa-methodology` | 测试策略、自动化、回归测试与质量门方法论 |

## 输出格式

采用产物金字塔。响应内容为 `00-index.md` 的绝对路径。
